WebHID Settings

Daemon as NM host

Talk to the daemon directly over native messaging (skip the webhid-native-messaging forwarder and Unix socket). Requires the webhid.daemon_nm_host native-messaging manifest to be installed and the daemon to run as your user (with the udev rule). Lower latency, but no root-daemon fallback. The addon reconnects automatically when toggled.

Data Plane

WebSocket: a Web Worker owns the WS connection to the daemon. Input reports are forwarded to the page via postMessage with ArrayBuffer transfer (off-main-thread, zero-copy).
WebTransport: the same worker architecture over QUIC, or directly in the page when Use Worker is off.
Native Messaging: route all data through the NM host via the content-script bridge. No WS. Fallback when WS/WT are blocked.

Use Worker

On: the WS/WT data plane runs in a dedicated Web Worker (off-main-thread, recommended). Off: WebTransport connects directly in the page (main-thread CPU). WebSocket still needs the worker (HSTS rewrites ws:// to wss:// on the page). Reload pages after changing.

Device Picker Mode

Modal: shadow-DOM overlay on the page when requestDevice() is called (default).
Page Action: URL-bar popup picker; the user clicks the icon to open it. Firefox only, Chromium falls back to modal.
Window: separate popup window.

Worker Polyfill

Inject WebHID API stubs into Web Worker scripts (new Worker(), new SharedWorker()). Methods throw NotSupportedError until full worker communication is implemented. Reload pages after changing.

Allow activation-less requestDevice()

Skip the user-activation requirement for navigator.hid.requestDevice() calls on this site.

Worker Spawn Mode

Shadow URL (default on MV3): spawns the data worker via new Worker(location.href) with a StreamFilter intercepting the synthetic self-request. Fails if the server rejects it or if require-trusted-types-for is restrictive.
Blob + CSP rewrite (default on MV2): spawns the worker from a blob: URL; relaxes the page's worker-src and connect-src directives.

Log Level

Console verbosity: Error = errors only, Warn = +warnings, Info = +info, Debug = +debug (includes timing). Reload pages after changing.
